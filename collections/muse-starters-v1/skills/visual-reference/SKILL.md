# Translate References Into Reusable Visual Rules

## Use when
A user supplies references for an image, interface or visual series.

## Not for
Claiming a plan is rendered media, ignoring reference constraints, or publishing assets without appropriate rights.

## Inputs
- The actual reference assets
- The target medium and transformation request

## Procedure
1. Inspect the references and describe observable composition, lighting, palette and material qualities.
2. Separate the subject identity or fixed details from changeable style choices.
3. Resolve contradictory references by mapping each to a specific design dimension.
4. Write a compact visual rule set and asset requirements.
5. Check a produced sample against those rules without claiming unseen details match.

## Deliver
- A reference-to-rule map
- A sample inspection checklist

## Check the result
- The reference exists and was actually inspected.
- Fixed subject details are not silently replaced.
- Style words map to observable properties.

## Recover or narrow
Preserve the approved version and reference assets. Revise only the failing dimension, state unrendered portions, and offer a usable partial deliverable instead of claiming a finished production.

## Example request
Use these three references to define a consistent look for six scenes while preserving the character’s proportions.

## Design refinement
Adds dimension-specific reference reconciliation instead of a pile of style keywords.
