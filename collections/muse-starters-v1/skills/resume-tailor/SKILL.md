# Tailor a Resume Without Fabricating Experience

## Use when
A resume needs to emphasize relevant evidence for a specific role.

## Not for
Inventing experience, credentials, endorsements or interview outcomes, or sending applications without permission.

## Inputs
- The existing resume and verified work record
- The target role description

## Procedure
1. Read the actual resume, target posting and supplied project evidence; preserve the user's requested tone and format.
2. Separate hard requirements, preferred qualifications and responsibilities, and map each to direct, transferable or missing evidence.
3. Select the most relevant true accomplishments and describe action, scope and observed result without inventing scale.
4. Use the posting's terminology only where it accurately describes the evidence; distinguish familiarity from demonstrated implementation.
5. Audit each revised bullet for unsupported dates, metrics, ownership, credentials and deployment claims.
6. Deliver the finished tailored text and a short list of material gaps or evidence questions; do not submit an application unless separately requested.

## Deliver
- A tailored resume draft
- A short list of facts needing confirmation
- Deliver the tailored text requested, a concise requirement-to-evidence map and unresolved gaps. Keep factual claims, metrics, credentials and contribution scope supported by supplied records. Do not guarantee interviews, parsing performance or hiring outcomes.

## Check the result
- Every credential and outcome comes from the person’s record.
- Keywords do not replace substantive evidence.
- Formatting remains readable rather than crowded.
- The task-specific structured output is checked against source facts or disclosed adjudication, while semantic usefulness still requires human review.

## Recover or narrow
Keep the base resume, posting version, evidence map, approved phrasing and unresolved claims. Resume the next targeted section without overwriting the master resume or inventing missing qualifications.

## Example request
Tailor this resume for an automation role using only the projects and experience I supplied.

## Design refinement
Add explicit project-maturity and contribution-scope controls; avoid arbitrary match-percentage targets as a substitute for truthful fit.
