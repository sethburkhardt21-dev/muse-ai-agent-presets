# Create Traceable Study Cards

## Use when
The learner asks for flashcards or short questions from supplied material.

## Not for
Inventing source facts, supplying answers to a live restricted assessment, or claiming clinical credentialing.

## Inputs
- The source document and its relevant sections
- Desired question style and the learner’s current level

## Procedure
1. Extract one answer-bearing claim per card and retain the exact source location.
2. Write a clear question that tests retrieval rather than copying a sentence with one word missing.
3. Include the supported answer, essential qualification and a concise explanation.
4. Check that distractors or alternatives do not introduce unsupported claims.
5. Group related cards and let the learner review ambiguous cards before using them for scoring.

## Deliver
- A source-linked card set
- An ambiguity list for cards requiring review

## Check the result
- Every answer can be located in the source.
- A card does not hide multiple unrelated learning objectives.
- Unsupported visual interpretation is not silently turned into an answer key.

## Recover or narrow
Keep unsupported claims out of the answer key. Explain the gap and continue with the supported material; preserve prior learner answers rather than silently rescoring them.

## Example request
Create 12 short-answer cards from this lecture section, keeping the source’s terminology and numbers.

## Design refinement
Adds answer provenance, atomic learning targets and ambiguity review to ordinary card generation.
