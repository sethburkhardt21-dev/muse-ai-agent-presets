# Review a Candidate for Delivery

Evaluate an exact candidate against its real acceptance criteria.

1. **Review a Change for Concrete Failure Paths** — load `skills/code-review/SKILL.md` for this step, carry forward the previous step's real output, and stop before any unapproved external effect.
2. **Check a Release Without Confusing Build and Delivery** — load `skills/release-readiness/SKILL.md` for this step, carry forward the previous step's real output, and stop before any unapproved external effect.

## Finish
Return source-bound findings, artifact checks and a scoped delivery decision without publishing.

A workflow is a sequence for Muse to follow, not a background service or dispatch permission.
