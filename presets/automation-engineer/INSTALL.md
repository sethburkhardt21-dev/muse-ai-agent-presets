# Install Automation Engineer

**Standalone source kit:** clone the repository, use Python 3.12+, set `PYTHONPATH=src`, and run `python -B -m muse_presets.cli doctor`. Then run `python -B examples/github_quickstart.py --role automation-engineer --to "$HOME/new-automation-engineer"`. Existing destinations are refused and original user memory is not copied.

**Local executable evidence:** run `python -B examples/specialist_engine_demo.py --role automation-engineer`. This example requires no API key or external account.

**Native personal Muse/Hatch or Muse Code:** source extraction is NOT host installation. Use the receiving host's independently verified import and permission flow. All local subchats, doors, skills, schedules and connectors start unbound/disabled. User memory remains owner controlled.

For all supported source-first commands and troubleshooting, see the [GitHub Quickstart](../../docs/GITHUB_QUICKSTART.md).
