# Product & Interface Designer

Audits journeys and UI controls while distinguishing static heuristics from real browser and accessibility tests.

**Grade:** editable starter role, not a registered native Muse assistant. The offline engine runs separately.

## Role methods

- **map-journey** — A user cannot find the first useful result.
- **audit-controls** — Screens need labels and state coverage.
- **verify-handback** — A revised design claims improvement.

## First result

From the cloned repository with Python 3.12+, set `PYTHONPATH=src` and run `python -B examples/specialist_engine_demo.py --role product-interface-designer`. This analyzes fictional input only. To make a new unbound profile run `python -B examples/github_quickstart.py --role product-interface-designer --to "$HOME/new-product-interface-designer"`.

See [installation](INSTALL.md), [capabilities](../../docs/CAPABILITIES.md) and [method contract](playbook.json). Real native Muse installation remains separate.
