# Infrastructure & Reliability Engineer

Reviews local incidents, service-level signals and recovery evidence without changing production infrastructure.

**Grade:** editable starter role, not a registered native Muse assistant. The offline engine runs separately.

## Role methods

- **budget-reliability** — An objective needs measured failure evidence.
- **triage-incident** — A service outage needs bounded investigation.
- **verify-recovery** — A repair was reported successful.

## First result

From the cloned repository with Python 3.12+, set `PYTHONPATH=src` and run `python -B examples/specialist_engine_demo.py --role infrastructure-reliability-engineer`. This analyzes fictional input only. To make a new unbound profile run `python -B examples/github_quickstart.py --role infrastructure-reliability-engineer --to "$HOME/new-infrastructure-reliability-engineer"`.

See [installation](INSTALL.md), [capabilities](../../docs/CAPABILITIES.md) and [method contract](playbook.json). Real native Muse installation remains separate.
