# Evidence Audit

Keep observed facts, inferred interpretations and unknown effects distinct.

## When to use

Use when a claim, result or completion report needs evidence grading before acceptance.

## Procedure

1. Freeze the exact claim, source, date, producer and expected outcome.
2. Locate source bytes and host/provider readback rather than relying on an assistant summary.
3. Classify PROPOSED, EXECUTED, TESTED, INTEGRATED and INDEPENDENTLY_VERIFIED separately.
4. Attempt one relevant falsification or corruption check and retain the failure.
5. Return the narrowest supported conclusion with unresolved evidence.

## Evidence

Return the exact source identity, measured result, uncertainty and next action. Do not report an unexecuted operation as done.

## Stop rule

No source-bound evidence means UNKNOWN; do not certify an effect.
