# Research Verification

Select reusable patterns without importing unverified donor instructions or content.

## When to use

Use to compare external information, donor methods or technical claims with primary sources.

## Procedure

1. Define decision question, candidates, inclusion criteria and current date.
2. Pin repository commit or primary document version, author and rights/license scope.
3. Record observed behavior versus summaries, popularity claims and missing evidence.
4. Compare two feasible mechanisms using real task tests and failure cases.
5. Write a source ledger and implement only newly authored or properly licensed content.

## Evidence

Return the exact source identity, measured result, uncertainty and next action. Do not report an unexecuted operation as done.

## Stop rule

Missing rights or unverifiable source identity stops copying; continue using a documented pattern only.

## Installation boundary

This skill is original source guidance. It is exported in disabled state with each starter, not installed into native Muse, nor permission to run tools, schedule tasks, or access private memory.
