# Consent And Effects

Prevent a role label or configuration file from becoming unauthorized tool authority.

## When to use

Use before a workflow would call a tool, modify owner data or contact external services.

## Procedure

1. Read actual provider capability, user direction, host grant and effect category.
2. Separate offline fixture, read-only observation and consequential external mutation.
3. Record cost, privacy scope, recipient identity, retry semantics and stop rules.
4. Request required owner approval through the supported provider before acting.
5. Verify the resulting effect with provider readback; preserve ambiguous outcomes.

## Evidence

Return the exact source identity, measured result, uncertainty and next action. Do not report an unexecuted operation as done.

## Stop rule

No authenticated permission or uncertain prior effect means no external action.

## Installation boundary

This skill is original source guidance. It is exported in disabled state with each starter, not installed into native Muse, nor permission to run tools, schedule tasks, or access private memory.
