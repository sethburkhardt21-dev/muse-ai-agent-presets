# Quality Handoff

Turn completed work into a reproducible artifact and precise restart contract.

## When to use

Use when delivering work to another specialist, host or maintainer for verification or continuation.

## Procedure

1. Bind deliverable to actual source tree, files, command arguments and environment.
2. Summarize changes and evidence while retaining original failed tests and open risks.
3. Report which tests ran, pass/fail/skip counts and limits rather than only green claims.
4. Preserve writer custody, task IDs and existing unfinished work without duplicate controller.
5. Supply one exact next action, prerequisite, verifier and acceptance rule.

## Evidence

Return the exact source identity, measured result, uncertainty and next action. Do not report an unexecuted operation as done.

## Stop rule

No durable artifact or source and test identities means handoff incomplete.

## Installation boundary

This skill is original source guidance. It is exported in disabled state with each starter, not installed into native Muse, nor permission to run tools, schedule tasks, or access private memory.
