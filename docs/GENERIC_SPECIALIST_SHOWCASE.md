# Generic specialist showcase — implemented capabilities and honest boundaries

This is a non-gothic, neutral, general-purpose showcase. The eleven assistants are configurable Muse-oriented specialist presets, not separate trained language models. Their roles and starter workflows do not include personal identities, memories, medical specialties, family information, account secrets or private training data.

The public repository combines newly authored general starter code with explicitly neutralized, tested functionality derived from owner-maintained original agents. A private source or skill is never automatically admitted into the public MIT repository: identity removal, dependencies, rights/provenance checks and independent regression evidence are required for each transfer.

## Honest release grades

- SOURCE_IMPLEMENTED: code and docs present in public GitHub.
- LOCAL_TESTED: exact source passes portable automated tests and synthetic demonstrations.
- HOST_WIRED: registered native tool plus original host readback — NOT CLAIMED.
- NATIVE_USED: original model/tool invocation under owner/session/task grant — NOT CLAIMED.
- INDEPENDENT_USEFUL: independently verified real outcome — NOT CLAIMED.

Evidence Finder demonstrates a newly authored shared engine; the Software Engineer Claim Gate demonstrates a separately neutralized, source-derived original engine. Further original-agent ports must satisfy the same provenance, portability, privacy, no-effect default and regression gates.

Showcase quality bar: working examples, clean neutral names, testable outcomes, accurate maturity, no fabricated deployments and no dependency on a private creator's account. The full public source, tests, examples and CI are checked by the [privacy release gate](PRIVACY_RELEASE_ASSURANCE.md); private source identities and historical blobs require an additional maintainer review.
