# Generic specialist showcase — implemented capabilities and honest boundaries

This is a non-gothic, neutral, general-purpose showcase. The eleven assistants are configurable Muse-oriented specialist presets, not separate trained language models. Their roles and starter workflows do not include personal identities, memories, medical specialties, family information, account secrets or private training data.

The public source is newly authored; more mature private systems are design references, not automatically copied into a public MIT-licensed repository.

## Honest release grades

- SOURCE_IMPLEMENTED: code and docs present in public GitHub.
- LOCAL_TESTED: exact source passes portable automated tests and synthetic demonstrations.
- HOST_WIRED: registered native tool plus original host readback — NOT CLAIMED.
- NATIVE_USED: original model/tool invocation under owner/session/task grant — NOT CLAIMED.
- INDEPENDENT_USEFUL: independently verified real outcome — NOT CLAIMED.

This Evidence Finder upgrade demonstrates a genuine public transfer of *functionality*, without copying a private development agent's source or rights-restricted assets. Other donor-derived engineering should follow under provenance, portability and safety gates.

Showcase quality bar: working examples, clean neutral names, testable outcomes, accurate maturity, no fabricated deployments and no dependency on a private creator's account.
