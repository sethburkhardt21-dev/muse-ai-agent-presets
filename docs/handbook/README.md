# Muse operating handbook

These first five guides turn the existing source toolkit into practical tasks. They do not install native assistants or promise access to a particular account. Start with the problem you have, not every configuration file.

| Need | Guide |
| --- | --- |
| The assistant is missing relevant context | [Load the right context](context-loading.md) |
| You want a useful method without changing your assistant | [Select and use a skill](skill-setup.md) |
| A side conversation needs a clear role and handoff | [Build a workroom](subchat-workrooms.md) |
| Important drafts need durable references and recovery | [Keep documents recoverable](durable-documents.md) |
| A local test is being confused with an installed tool | [Understand capability boundaries](source-and-host-capabilities.md) |

[Daily Desk](daily-desk-design.md) is the next app design contract, not a deployed Space. [Specialist collection](../collection/MUSE_CURATED_COLLECTION.md) provides 75 task procedures, 25 workflows and 100 starter choices; [existing profiles](../GITHUB_QUICKSTART.md) remain optional and unchanged. These are six current authored documents, not the planned fifty-guide handbook already completed.
