## Harvest pipeline

`DISCOVER → PIN SHA → RIGHTS/PRIVACY/DEPENDENCY REVIEW → CHECK EXISTING EQUIVALENT → SELECT MINIMAL MODULE → SANDBOX TEST → NATIVE HOST CANARY → INDEPENDENT REVIEW → VERSIONED RELEASE`.

Record exact URL, commit, source path, license (including asset-specific restrictions), tool permissions, network/cost risks, test provenance, selected module and admitted result. `ADOPT/ADAPT/LINK/REFERENCE/REJECT` are separate decisions. Vendor SDK mirrors and leaked prompts are not distributable source. No `curl | sh` or blind source updates.
