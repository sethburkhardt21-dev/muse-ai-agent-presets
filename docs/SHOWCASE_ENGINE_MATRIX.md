# Generic showcase engine adoption matrix

The goal is **eleven strong, reusable general-purpose specialist presets
plus one shared Evidence Finder**, not eleven reskinned personal assistants.
Each role keeps its own generic identity and responsibilities, while
reusable engines are admitted once and shared where appropriate.
No gothic naming, personal medical curricula, private family information,
or private-host material is part of the showcase.

**Current public grade:** Portable Python modules, local tests and safe
synthetic demos. No native Muse identity, registered host execution, external
model or multi-agent transport.

| --- | --- | --- |

## Integration admission — five common seams

1. **S1 source custody:** pin exact donor and incoming bytes before use.
2. **S2 authorization:** never infer identity from an input role label.
3. **S3 execution:** prove the original callable, not merely a stub.
4. **S4 recovery:** persist idempotent operation IDs; hold uncertain effects.
5. **S5 outcome:** reopen the original result and use independent review when needed.

No generic preset inherits another assistant's private identity, memory,
permissions, credentials, protected datasets or external signing authority.
Source rights and license compatibility must be verified before any donor
implementation is copied into this public MIT repository.

**Not yet public-integrated:** The other specialist donor engines, native
Muse tools/Spaces and external Family Link. An internal tested overlay or
VM capability must not be described as public until its generalized
implementation and tests land here.
